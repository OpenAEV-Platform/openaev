# Every statement that reads or writes grants. Read by GrantReaderAllowlistArchTest.
#
# A grant applies in the tenant of the group that holds it, and in every tenant when that group is a
# platform group. grants has no tenant column, so each reader carries the rule itself, or says why it
# does not need to.
#
# Format, one statement per line:
#   <Class>#<method>  # <classification> : <reason>
#
# The reason must BEGIN with one of these classifications:
#
#   group-tenant : the statement restricts the grant's group to the request's tenant or to a platform
#                  group. Checked: the statement must carry "x.tenant IS NULL OR x.tenant.id =" (or
#                  the tenant_id form), or call SpecificationUtils.groupCountsInTenant. Required for
#                  any reader that can match a resource id repeating across tenants, which today
#                  means THREAT_ARSENAL grants on injector contract ids.
#   unique-id    : the ids the grants are matched against are single-column primary keys (scenario,
#                  simulation, inject, autonomous run), so a grant names one row in one tenant and
#                  the group's tenant is that row's. Say what the ids are matched against.
#   write        : the statement changes grants. Say what keys it.
#   dead-code    : the method has no caller. Say how that was established.
#
# The size of this list is frozen in the test: removing a reader takes its line out and the constant
# down in the same change.
#
# Lines starting with # and blank lines are ignored.

# ---------------------------------------------------------------------------------------------
# Restricted to the group's tenant.
# ---------------------------------------------------------------------------------------------

InjectorContractRepository#getAllRawInjectorsContractsGranted  # group-tenant : the granted contract list; the group is correlated to the contract's own tenant, which the statement pins to the current one.
