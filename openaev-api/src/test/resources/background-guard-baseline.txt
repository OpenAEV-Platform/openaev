# Background-guard baseline (T1.6, #6398).
#
# The five background entry-point families (Quartz jobs, @Async methods, event listeners,
# seeding/startup, detached thread hand-offs) are enumerated by
# BackgroundEntrypointTenantScopeArchTest. Every entry point must either reference
# TenantScopedTransaction (the primitive carries the scope) or be listed here with a reason.
#
# Format, one class per line: <fully.qualified.ClassName>  # <reason>
# The reason is one of three, spelled out, never assumed:
#   touches-no-tenant-table : reads and writes nothing with a tenant_id column (i.e. no entity that
#                             implements io.openaev.database.model.TenantBase). Say what it touches.
#   delegates-to-<Class>#<m> : the scope is set by a service/method it calls (name it).
#   platform-global         : it operates on platform rows or across tenants by design; say why.
#
# This file is hand-authored and reviewed. It may only shrink: once a path is scoped through the
# primitive, remove its line (the stale-entry check fails the build until you do). A run never
# rewrites it. Lines starting with # and blank lines are ignored. The first '#' on an entry line is
# the reason delimiter; a '#' inside a reason (a method name) is kept verbatim.

# --- Seeding and startup: platform singletons and infrastructure, no per-tenant business rows -----

io.openaev.runner.InitAdminCommandLineRunner  # platform-global: bootstraps the singleton admin User/Token (Base) and attaches them to the default tenant and the platform admin groups with an explicit DEFAULT_TENANT_UUID
io.openaev.service.tenants.TenantQueueService  # platform-global: enumerates the Tenant registry to declare each tenant's broker queues at startup; infra setup, touches no TenantBase business row
io.openaev.rest.inject.InjectApi  # platform-global: @PostConstruct only wires the platform inject-trace RabbitMQ queue (DEFAULT_TENANT_UUID) at startup, no TenantBase entity access

io.openaev.service.chaining.WorkflowScopeRuleCascadeListener  # touches-no-tenant-table: deletes WorkflowScopeRule (implements Base only, no tenant column) in the deleter's transaction

io.openaev.aop.audit_log.AuditLogger  # touches-no-tenant-table: emits LogEvent audit documents to the engine transport (not a JPA entity); the tenant id is copied from the request thread context, no tenant-scoped row is written
