# Background-guard baseline (#6398).
#
# The six background entry-point families (Quartz jobs, @Async methods, @Scheduled methods, event
# listeners, seeding/startup, detached thread hand-offs including inline CompletableFuture *Async
# methods, new Thread, and an executor obtained and used inline such as Executors.new*().execute(...)
# or ForkJoinPool.commonPool().submit(...)) are enumerated by BackgroundEntrypointTenantScopeArchTest.
# The Quartz, listener and seeding/startup families are also recognised on a @Bean factory whose
# return type is that family's type (a @Bean CommandLineRunner/ApplicationListener/Job). Every entry
# point must either reference TenantScopedTransaction (the primitive carries the scope) or be listed
# here with a reason.
#
# Format, one class per line: <fully.qualified.ClassName>  # <reason>
# The reason must BEGIN with one of these four classifications, spelled out, never assumed. Any other
# text (e.g. "temporary") is rejected: an entry must carry real evidence, and an until-active waiver
# must be spelled as one so it has a tag to expire.
#   touches-no-tenant-table : reads and writes nothing with a tenant_id column (i.e. no entity that
#                             implements io.openaev.database.model.TenantBase, and no dual-scope
#                             tenant-bearing table). Permanent: NO until-active tag (nothing
#                             activates to make it wrong). Say what it touches.
#   delegates-to-<Class>#<m> : the scope is set by a service/method it calls (name it, the #method
#                             separator is required). An until-active tag is allowed but optional.
#   platform-global         : it operates on platform rows or across tenants by design; say why.
#                             Permanent: NO until-active tag.
#   cross-tenant-resolve    : it resolves a row in another tenant by a globally-unique id, honest
#                             only while its table stays v1. MUST carry an until-active:<table> tag,
#                             or nothing expires the waiver.
# After the classification, free text and (where allowed above) an until-active:<table> tag may
# follow, separated by a colon or a space. The <table> is token-bounded: until-active:injects-typo
# is not a valid tag (a hyphen ends the name), so a cross-tenant-resolve whose only tag is malformed
# is rejected rather than silently expiring against the wrong table.
#
# A waiver that is honest only while some table is still v1 (the path resolves cross-tenant, or runs
# an unscoped read/write that a v2 activation would turn into a wrong-tenant access) must carry an
# 'until-active:<table>' tag in its reason, naming that table. The build fails the day <table> is in
# openaev.tenant.active-tables (or the allowlist is the '*' wildcard, which activates every strict
# table), so the waiver cannot outlive the reason it was granted. The named table must be a real
# tenant-aware table, or the tag can never expire and the guard rejects it.
#
# This file is hand-authored and reviewed. New entries are stopped only by review (the checks below
# enforce that every entry carries a reason and that no entry is stale, not that the list only ever
# shrinks). Once a path is scoped through the primitive, remove its line (the stale-entry check
# fails the build until you do). A run never rewrites it. Lines starting with # and blank lines are
# ignored. The first '#' on an entry line is the reason delimiter; a '#' inside a reason (a method
# name) is kept verbatim.
