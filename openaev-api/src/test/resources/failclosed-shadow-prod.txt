# Fail-closed shadow reference for the "shadow-prod" mode: the suite run with every tenant table
# gated, as main ships. One production call site per line (class.method, no line number), exactly the
# grammar of failclosed-baseline.txt.
#
# This is NOT a waiver list and it carries no safety claim. It says only which unscoped production
# signatures that armed set is already known to produce, so a shadow run can report the ones that
# are NEW. A signature here has not been judged benign; it has been seen before. A signature judged
# benign or scoped-ok belongs in failclosed-baseline.txt with its reason, which is read in every
# mode, and never here.
#
# No CI job arms this mode: a run sets openaev.failclosed.shadow-mode by hand and reads
# failclosed-shadow.txt next to the surefire reports. To curate a new signature: triage it, then
# scope the path, or waive it in failclosed-baseline.txt with a reason, or add it here if it is a
# known consequence of arming this wider list.
#
# Deliberately empty: a list generated from a run with known-red shapes in it silently blesses
# whatever is broken in that run.
#
# Lines starting with # and blank lines are ignored.
