# Call sites that resolve ids on the repository of an active tenant table without a tenant, read by
# LinkedIdResolutionArchTest: findAllById, getReferenceById, or a declared findAllByIdIn* method with no
# Tenant in its name and no tenantId parameter, as a call or as a method reference.
#
# Ids named in a request body resolve with findAllByIdInTenant(ids, tenantId) and the tenant of the entity
# written, the way TagRepository does it: an id of another tenant is then treated like an unknown id.
#
# Format: <fully.qualified.Class>#<method> -> <Repository> | <kind> | <calls> | <what the site does>
#   link   the site resolves ids named in a request body and links the rows to the entity written (a
#          service wrapper is a link when at least one of its callers does). It is debt: the line leaves the
#          file when the site is converted, and LINK_DEBT_SIZE goes down in the same change. A site that
#          cannot be classified by reading is a link.
#   other  the site does something else; the reason says what (a path id, an export, a bulk delete, an
#          options lookup, a read of stored ids).
#   calls  how many calls and method references the method holds on that repository, at least 1. A call
#          added to a listed method, or removed from it, fails until the number is changed here. The
#          calls of a lambda belong to the method that creates it.
#
# The file only shrinks. A newly activated table's link sites are converted in the change that activates
# it. An other line may be added in review, with its reason, when an activation adds a site that is not
# a link.
