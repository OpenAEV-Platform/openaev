# Test classes that run with an openaev.tenant.active-tables list not holding the production one,
# read by PinnedActiveTablesArchTest.
#
# A class that pins its own list keeps testing the list it was written with. When production
# activates another table, the class does not arm it, so a path through that table runs there with
# no isolation at all while production runs it under the inspector. A test therefore follows the
# production list: ProductionActiveTables in a @DynamicPropertySource, plus its own tables on top
# when it needs more. Such a registration is judged by the value it registers, not by how it is
# written, so it follows production only while that value holds every production table. A class
# that pins on purpose says why, here.
#
# Format: <fully.qualified.Class> | <tables, sorted> | <kind>[ until-active:<table>,...]: <why>
#   The tables column is the list the class runs with: the annotation's value, or the value its
#   @DynamicPropertySource registered when the guard evaluated it, "none" for an empty list, or
#   "unevaluated" when the registration could not be run outside Spring (a supplier reading state
#   only a running test provides). The guard checks it against the class, so a changed pin brings
#   its reason back under review.
#
# Kinds:
#   probe    every assertion is about rows of the tables it arms, or a mechanism measured on them,
#            and none is that a flow works; a table production activates beside it decides nothing.
#            A class that tests that a flow works (an endpoint, a job or a service call succeeds and
#            returns or writes the expected data) is a probe only if it arms every production table
#            that flow reads.
#   control  leaves a table off on purpose, to show that another mechanism holds on its own. It
#            names in until-active:<table> the activation that retires that mechanism; the line fails
#            once production arms one of those tables.
#   drifts   an assertion depends on how a production table outside its list is scoped, or it tests
#            that a flow works without arming every production table the flow reads, so the class
#            tests less than production does. Debt: move it to the production list and delete the
#            line.
#
# A read counts when it goes through Hibernate, so the inspector rewrites it: a repository call, a
# query, an eager association, a lazy one initialised by the flow or by serialising its response.
# Three reads decide nothing here: a JdbcTemplate query, which the inspector never rewrites; the
# scope primitive's own clearance lookup, which carries an explicit tenant predicate; and the
# current user's load.
#
# A new probe or control line raises DELIBERATE_SIZE in review. A drifts line is never added, and
# removing one lowers DEBT_SIZE in the same change.
