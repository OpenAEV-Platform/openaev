Comment ça change

  • ✅ Avant: Action liait vers upstream_action.output_type.field
  • ✅ Après: Action lie vers event.contract.type.field
  • ✅ Le source affiche "Event: Port Found → port.number"
  • ✅ Si l'Event change de provider (autre action en amont), les bindings restent valides
  • ✅ Le Link menu (🔗) propose les outputs du contrat de l'event parent

💡 Principe clé

L'Event joue le rôle d'interface / contrat entre les actions productrices (upstream) et les actions consommatrices (downstream). Si on change l'action productrice (ex: remplacer Nmap par Masscan), tant que le contrat de l'Event est respecté, les actions en aval n'ont rien à changer.
